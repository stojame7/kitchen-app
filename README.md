# MenuWeave

**Your culture. Your taste. Your plan.**

MenuWeave builds personal meal timetables for African kitchens, shaped by where you live, the food traditions you grew up with, your faith and the way you like to eat.

- **Live app:** https://stojame7.github.io/kitchen-app/
- **Documentation:** https://stojame7.github.io/kitchen-app/docs.html

## What's in this repository

| File | What it is |
|---|---|
| `index.html` | The whole app (HTML, CSS and JavaScript in one file) |
| `docs.html` | Documentation: features, brand, setup, data model, roadmap |
| `supabase-setup.sql` | Creates the user and saved-timetable tables in Supabase |

## Quick start

1. Create a free Supabase project and run `supabase-setup.sql` in its SQL Editor.
2. Paste your Supabase Project URL and anon key into `CONFIG` near the top of the script in `index.html`.
3. Upload `index.html` here. GitHub Pages publishes it within a couple of minutes.

Full steps are in [docs.html](docs.html#setup).
